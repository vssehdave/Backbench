# 5.12 Rolling down the yield curve

- Section: 5.12
- Asset class: Fixed income
- Harness status: **not testable: bonds/rates** - needs bond, yield-curve or swap data and positions; the harness trades one daily equity or BTC series.

## Description (paper)

The objective of this strategy is to capture the "roll-down" component C roll ( *t, t + ∆ *t, T) of bond yields. These returns are maximized in the steepest segments of the yield curve. Therefore, the trader can, e.g., buy long- or medium-term bonds from
